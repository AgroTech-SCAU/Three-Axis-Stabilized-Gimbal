# Three-Axis Stabilized Gimbal Retarget Simple Fix

STM32H723 三轴增稳云台，达妙与高擎共用 FDCAN1

## 使用

1. 上电放稳，等待 IMU 标定和电机反馈就绪
2. 自动捕获当前姿态进入增稳，蓝灯常亮
3. 按 PA15 请求三轴失能，绿灯常亮后拖动云台瞄准
4. 再按 PA15，黄色慢闪等待输入与握手，接管成功后蓝灯常亮，以当前姿态增稳

切换只更新增稳目标，不改机械零位，不重新标定 IMU

初始化期间按键不会跳过标定，长按只触发一次

安全停止后的首次按键只确认故障，沿用原有恢复流程

启动标识为 `BOOT gimbal-retarget-simple-20261119`

## RGB

| 状态 | RGB |
|---|---|
| 初始化、标定、反馈等待、切换准备 | 黄色慢闪，亮 500 ms、灭 500 ms |
| 增稳 | 蓝色常亮 |
| 手动瞄准 | 绿色常亮 |
| 实际故障、安全停止 | 红色快闪，亮 125 ms、灭 125 ms |

故障优先显示，运行中短暂等待输入时显示黄色慢闪

绿灯要求三轴禁能指令提交成功且收到后续有效反馈，达妙还检查失能状态码

高擎反馈没有独立的失能确认位，绿灯不能替代实机检查

## 切换

- 手动模式持续读取 IMU 与编码器，冻结零偏学习，禁止保持指令和自动使能
- 手动模式跨 CAN 恢复保留，反馈恢复不会自行回到增稳
- 重新接管前检查反馈时效、现有机械限位和姿态可控性
- 短暂缺少新鲜输入时保留恢复请求，持续黄色慢闪，数据齐备后自动继续
- 机械条件不满足时保持黄色等待，不发使能指令，再按 PA15 可取消并调整姿态
- 重新接管时清除旧目标、滤波状态和待重发指令，从当前编码器位置开始控制
- 达妙模式确认后重新查询位置，收到新的失能反馈后才预置当前位置并使能
- 预置位置仍要求 20 ms 内的新鲜反馈，发送忙时限频重试，不使用握手前的旧位置
- 等待与握手全程黄色慢闪，普通通信延迟不会导致自动退出
- 若达妙握手失败并重新失能，上层仅对该轴限频重试，不要求重复按键
- 只有再次按 PA15 才回到绿色手动，机械条件异常只阻止使能而不自动退绿
- 日志保留取消原因和单轴重新使能请求
- 握手期间再次按 PA15 可取消恢复

达妙失能期间通过官方状态读取命令持续查询角度

协议参考 [motor-sdk DM_CAN.py](https://github.com/dmBots/motor-sdk/blob/main/Python%E4%BE%8B%E7%A8%8B/u2can/DM_CAN.py)

## 坐标

- IMU 为 X 前、Y 左、Z 上
- 机构顺序为外 Yaw 绕 Z、中 Roll 绕 X、内 Pitch 绕 Y
- 三轴右手正方向，机械中位为 0，比例为 1
- 工作范围为三轴 ±45°
- 内部角度 rad，摘要同时显示 rad 与 deg

手动拖动不受软件工作范围约束，范围外禁止重新接管，不会自动拉回限位内

## 串口

USART1 使用 921600 baud、8N1，命令以 LF 或 CRLF 结束

| 命令 | 功能 |
|---|---|
| `status` | 输出当前状态 |
| `log on` / `log off` | 开关 1 Hz 摘要 |
| `raw on` / `raw off` | 开关 10 Hz 原始数据，10 秒自动结束 |
| `help` | 列出命令 |

日志整帧输出，首尾帧号一致，空间不足时整帧丢弃并计数

状态包括 `STARTING`、`RUN`、`RUN_WAIT`、`MANUAL_WAIT`、`MANUAL`、`REARMING`、`SAFE_STOP`

手动模式的 RAW 目标显示 `nan`，表示没有位置目标
