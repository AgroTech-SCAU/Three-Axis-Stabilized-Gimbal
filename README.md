# 三轴农业巡检云台

面向农业巡检视觉载荷的 STM32H723 三轴云台控制工程。代码围绕 BMI088 姿态反馈、CAN 电机通信和 Yaw、Pitch、Roll 三轴控制展开，支持多光谱与 RGB-D 载荷的稳定观测方案。

## 代码结构

| 路径 | 内容 |
| --- | --- |
| `src/app/entry.h` | 主循环入口、传感器与电机状态交接 |
| `src/app/gimbal_control.c/.h` | 三轴控制及 Yaw 角速度前馈 |
| `src/app/app_control.c/.h` | 应用层控制逻辑 |
| `src/device/` | IMU、电机与其他设备接口 |
| `src/domain/` | 控制相关领域逻辑 |
| `Core/Src/main.c` | STM32 工程入口；其余 CubeMX 生成文件不在本仓库中 |
| `robot.ioc` | STM32CubeMX 配置 |
| `Yaw前馈说明.md` | 前馈计算、参数与验证边界 |

## 技术要点

- 使用 BMI088 姿态信息与 CAN 电机反馈构成闭环控制链路。
- 在 Yaw 控制中加入角速度前馈，并保留原有反馈控制与限幅流程。
- 速度反馈缺失或无效时跳过前馈，避免使用失效数据；具体实现与参数见 `Yaw前馈说明.md`。
- 通过模块化设备接口和应用控制层组织三轴算法与通信。

## 构建与调试

本仓库保留项目源码和 `robot.ioc`；完整的 CubeMX 生成文件、HAL/CMSIS 驱动和构建产物未纳入版本控制。构建时先用对应版本的 STM32CubeMX 根据 `robot.ioc` 生成 STM32H723 工程，再接入本仓库的 `src/` 与 `Core/Src/main.c`。接入电机前，应先检查供电、CAN 终端、电机 ID、方向符号与限幅；先在低输出条件下验证三轴反馈方向，再逐步整定参数。`Yaw前馈说明.md` 中的前馈时间与滤波常数是调试初值，需按实际机构测试。

本目录是本地开发快照。编译结果与实机性能应以所用工具链、硬件版本和现场测试为准。第三方 HAL/CMSIS 代码保留原有许可声明；不要把依赖库视为个人原创。
