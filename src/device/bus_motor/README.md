# 总线电机接口

`bus_motor` 提供统一配置、反馈和控制接口，私有参数通过 `driver_config` 传入

当前云台使用 DM ID 1 与 HT ID 8/2，共用 FDCAN1

项目装配负责握手、反馈时效和目标提交，协议编码留在设备层

| 实现 | 用途 |
|---|---|
| `dm_motor.*` 与 `dm_motor/` | 达妙驱动与协议版本 |
| `ht_motor.*` | 高擎驱动 |
| `dji_motor.*` | 保留 M3508/C620 与 M2006/C610 兼容接口 |
| `agv_motor.*` | 保留通用兼容实现 |

角度使用 rad，角速度使用 rad/s，云台方向、比例和机械零位在项目配置中换算

DJI 反馈按输出轴换算，型号由 `DjiMotorConfig` 指定，未提供时使用原 M2006 默认值
